# Bilan visuel

Application web installable (PWA) pour examens de vue et adaptation en lentilles (souples et rigides), avec contrôle réglementaire et comptes rendus à transmettre à l'ophtalmologiste.

## Installation depuis GitHub
1. Remplacer les fichiers du dépôt par ceux-ci (index.html, manifest.json, sw.js, icon.svg).
2. Settings > Pages > branche main, dossier / (root).
3. Ouvrir l'adresse https://VOTRE-NOM.github.io/NOM-DU-DEPOT/ sur le téléphone, puis installer l'appli (Chrome : menu > Installer ; Safari : Partager > Sur l'écran d'accueil).
4. Onglet Réglages : saisir vos informations (cabinet, n° d'enregistrement) et vos ophtalmologistes.

Les données restent sur le téléphone. Les règles de contrôle (validité des ordonnances, adaptation, critères de l'arrêté du 25/10/2016) sont des repères : vérifiez les textes en vigueur.
