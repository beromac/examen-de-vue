# Bilan visuel

Application web installable (PWA) : examens de vue, adaptation en lentilles, lettre et compte rendu.

## Mise en ligne (GitHub Pages)
1. Déposer tous les fichiers du zip à la racine d'un dépôt GitHub (index.html, manifest.json, sw.js, icon.svg, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png).
2. Settings > Pages > branche main, dossier / (root).
3. Ouvrir https://VOTRE-NOM.github.io/NOM-DU-DEPOT/ directement dans Chrome (Android) ou Safari (iPhone).

## Installer sur le téléphone
- Android (Chrome) : menu ⋮ > Installer l'application (ou le bouton dans Réglages > Installer l'application).
- iPhone (Safari) : Partager > Sur l'écran d'accueil.

## Si le téléphone répond « application déjà installée » ou n'ajoute qu'un simple lien
- Supprimer l'ancienne icône ou l'ancien raccourci (appui long > Désinstaller / Supprimer).
- Chrome : Paramètres du site > Effacer les données du site, puis rouvrir l'adresse.
- Ne pas ouvrir l'adresse depuis un lien dans WhatsApp, Gmail, Facebook, etc. : copier le lien et le coller dans Chrome ou Safari.
- Cette version a un identifiant propre (« bilan-visuel-opticien ») et des icônes PNG : elle est reconnue comme une nouvelle application.
