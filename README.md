# Bilan visuel

Application web installable (PWA) pour examens de vue et adaptation en lentilles souples et rigides.

## Installation depuis GitHub
1. Créer un dépôt GitHub et y déposer tous les fichiers (index.html, manifest.json, sw.js, icon.svg).
2. Settings > Pages > Source : branche main, dossier / (root). Enregistrer.
3. Ouvrir l'adresse https://VOTRE-NOM.github.io/NOM-DU-DEPOT/ sur le téléphone.
4. Android (Chrome) : menu ⋮ > Installer l'application. iPhone (Safari) : Partager > Sur l'écran d'accueil.

Fonctionne hors connexion après la première ouverture. Les données restent sur le téléphone. Imprimer : onglet Compte rendu > Imprimer.
